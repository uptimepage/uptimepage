# Security Policy

## Reporting a vulnerability

Email **security@uptimepage.dev** with subject `[SECURITY]`.

**Please do not** open a public GitHub issue for security 
vulnerabilities.

## What to include

- Description of the issue
- Steps to reproduce
- Impact assessment
- Whether you've disclosed it elsewhere

## Response timeline

- Acknowledgement: within 48 hours
- Initial assessment: within 7 days
- Fix timeline depends on severity

For the hosted service, the [Security Policy](https://uptimepage.dev/security-policy) 
adds severity definitions, scope, and coordinated disclosure terms.

## Safe harbor

Good-faith security research consistent with this policy will not 
result in legal action.

## Acknowledgements

Researchers who report a valid issue are credited here with the name and 
optional link they provide. Anonymous reports are welcome and simply not 
listed.
